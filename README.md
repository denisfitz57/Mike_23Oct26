# Mike's audio story

This folder is ready for GitHub Pages. The audio is embedded in index.html. No installation or build is needed.

1. Create a GitHub repository (a public repository works with GitHub Free).
2. Upload index.html and .nojekyll to its top level. The README is optional.
3. Open repository Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Open the website address shown in Settings > Pages once deployment finishes.

The finished site contains the edited audio, clickable transcript, chapter navigation, and editorial notes. The original full recording and unrelated conversation are not included.

A public Pages site makes Mike's voice and personal account accessible to anyone with its address. The embedded audio can be downloaded by visitors.
